# Adivinhe O Número
Um jogo de adivinhar números (de 0 a 100), na linguagem de programação C.

## Requisitos
- O programa deve, depois do número escolhido, receber inputs (tentativas) do jogador.
- O programa deve dar um feedback claro para o jogador se sua tentativa ficou acima ou abaixo do numero escolhido.
- O programa deve funcionar no terminal.
