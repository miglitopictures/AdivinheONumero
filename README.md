# Adivinhe O Número

Um jogo de adivinhar números, desenvolvido em linguagem C utilizando a biblioteca **Raylib** para a interface gráfica.

## O que o programa faz?
- O sistema sorteia um valor aleatório dentro de um intervalo definido.
- O jogador insere palpites para tentar acertar o número.
- O programa fornece feedback visual se a tentativa foi acima ou abaixo do número correto.
- O jogo evoluiu de uma versão em terminal para uma interface gráfica intuitiva.

## Histórias de Usuário (Backlog)

| ID | Título | Descrição |
|:---|:---|:---|
| **UH1** | Seleção de Dificuldade | Como jogador, quero escolher entre diferentes níveis (10, 100, 1000, 10000) para ajustar o desafio. |
| **UH2** | Modo Trilha | Como jogador, quero um sistema de progressão linear para perceber minha evolução técnica entre as fases. |
| **UH3** | Feedback de Proximidade | Como jogador, quero saber se estou "quente" ou "frio" para refinar minha estratégia de chute. |
| **UH4** | Acessibilidade | Como jogador com deficiência visual, quero feedbacks sonoros para jogar de forma autônoma. |
| **UH5** | Limite de Tentativas | Como jogador, quero um número limitado de chances para que o jogo exija mais raciocínio e risco. |
| **UH6** | Persistência de Recorde | Como jogador, quero que minha melhor pontuação (High Score) seja salva localmente entre sessões. |
| **UH7** | Mensagens de Resultado | Como jogador, quero mensagens imersivas e distintas para vitória ou derrota ("Game Over"). |
| **UH8** | Histórico de Palpites | Como jogador, quero visualizar meus últimos 5 chutes na tela para evitar repetições por esquecimento. |
| **UH9** | Reinício Rápido | Como jogador, quero reiniciar a partida instantaneamente (tecla 'R') sem precisar reabrir o jogo. |
| **UH10** | Palpite Repetido | Como jogador, quero ser avisado se repetir um número já tentado, sem perder vidas por isso. |
